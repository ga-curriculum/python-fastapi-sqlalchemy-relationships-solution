# Python FastAPI SQLAlchemy Relationships Solution

## About

This is a completed version of the [Python FastAPI SQLAlchemy Relationships](https://pages.git.generalassemb.ly/modular-curriculum-all-courses/python-fastapi-sqlalchemy-relationships/canvas-landing-pages/fallback.html) module.

## Getting Started

1. Fork and clone this repo.
2. Install the dependencies and start the development server:

```bash
pipenv install
pipenv run uvicorn main:app --reload
```

Open the application in VSCode:

```bash
code .
```
